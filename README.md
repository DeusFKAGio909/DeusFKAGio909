## 🔒 &nbsp;Proof — evidence over claims *(NDA-safe)*

La mayor parte de mis proyectos son **privados / confidenciales** (industria + gobierno). Muestro **evidencia agregada** — sin clientes, datos sensibles ni IP.

<details>
  <summary><b>📈 &nbsp;Métricas que sigo (lenguaje de gerencia)</b></summary>

<br/>

| Eje | Métricas |
|-----|----------|
| **Entrega** | Lead / cycle time · reducción de tiempo de reporting |
| **Confiabilidad** | Disponibilidad (SLA / SLO) · frecuencia de incidentes · MTTR |
| **Datos** | Completitud · consistencia · normalización · duplicados |
| **Negocio** | Unit economics (margen, CAC / LTV) · forecast vs. actual |

</details>

<details>
  <summary><b>🏛️ &nbsp;Public-sector analytics (Chile) — framework, sin exponer IP</b></summary>

<br/>

Framework de análisis orientado a decisiones sobre datos de ecosistemas públicos (ej. mercado público): **trazabilidad**, **calidad**, **segmentación** y **hallazgos accionables**.

Indicadores publicables sin romper confidencialidad: cobertura temporal · volumen procesado · entidades modeladas · dimensiones (rubro, región, institución, proveedor, tiempo, modalidad) · calidad de datos · outputs (ranking, concentración, canasta, estacionalidad, anomalías).

> El detalle se conversa **bajo NDA**.

</details>
